Интеграция с WUD (Whats Up Docker) для Homeassistant через модуль HACKS
1. REST интеграция через стандартный порт 3000 (на моём сервере 3002)
2. Для проверки используй сервер по адресу 192.168.1.150. Логин - admin, пароль - admin
3. Проект WUD с подсказками для Claude и описанием находится здесь `/Users/alexeykin/IdeaProjects/wud`
4. Интеграция должна создавать update сущности с возможностью вызова обновления:
   1. Описание обновления из github
   2. Кнопка обновление
   3. Процент обновления на основе каких-то этапов
   4. Иконки и описание для обновлений брать из api, либо из mqtt-интеграции
